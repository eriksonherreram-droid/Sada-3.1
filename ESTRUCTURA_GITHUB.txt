ESTRUCTURA RECOMENDADA PARA GITHUB

Tu repositorio en GitHub debería verse así:

sada-analytics/
│
├── README.md                          ← Descripción principal (lo primero que ven)
├── SADA_Professional.html             ← Aplicación web principal (NO renombrar)

├── LICENSE                            ← Licencia MIT (opcional pero recomendado)
│
├── docs/
│   ├── MANUAL_USUARIO.md              ← Guía de usuario (convertido de .txt a .md)

│   └── Base_Datos_SADA.xlsx           ← Datos de ejemplo
│

    ├── logo.svg                       ← Logo SADA (opcional)
    └── screenshots/                   ← Capturas de pantalla
        ├── login.png
        ├── dashboard.png
        ├── usuarios.png
        └── analisis.png

═══════════════════════════════════════════════════════════════════════════════
PASOS PARA CREAR EL REPOSITORIO EN GITHUB
═══════════════════════════════════════════════════════════════════════════════

PASO 1: Crear el repositorio en GitHub
────────────────────────────────────────
1. Ve a https://github.com/new
2. Repository name: "sada-analytics"
3. Description: "Plataforma integral de análisis académico"
4. Selecciona: Public (para que vean tu trabajo)
5. Crea el repositorio

PASO 2: Clonar el repositorio localmente
─────────────────────────────────────────
$ git clone https://github.com/TU_USUARIO/sada-analytics.git
$ cd sada-analytics

PASO 3: Agregar los archivos
────────────────────────────
Coloca en la carpeta sada-analytics:
  ✓ README.md
  ✓ SADA_Professional.html
  ✓ .gitignore
  ✓ LICENSE (opcional)
  
  Y las carpetas:
  ✓ docs/
    └── MANUAL_USUARIO.md
  ✓ data/
    └── Base_Datos_SADA.xlsx
  ✓ assets/
    └── screenshots/

PASO 4: Subir a GitHub
──────────────────────
$ git add .
$ git commit -m "Initial commit: SADA Analytics v1.0"
$ git push origin main

PASO 5: Verificar en GitHub
────────────────────────────
Ve a https://github.com/TU_USUARIO/sada-analytics
¡Deberías ver todos tus archivos!

═══════════════════════════════════════════════════════════════════════════════
COMANDOS GIT BÁSICOS
═══════════════════════════════════════════════════════════════════════════════

1. CLONAR REPOSITORIO:
   $ git clone https://github.com/usuario/sada-analytics.git

2. AGREGAR CAMBIOS:
   $ git add .                  # Agregar todos los archivos
   $ git add archivo.html       # Agregar archivo específico

3. HACER COMMIT:
   $ git commit -m "Descripción del cambio"

4. SUBIR A GITHUB:
   $ git push origin main       # Subir a rama principal

5. VER ESTADO:
   $ git status                 # Ver qué cambios hay
   $ git log                    # Ver historial de commits

6. ACTUALIZAR DESDE GITHUB:
   $ git pull origin main       # Descargar cambios

CONVERTIR .txt A .md (MARKDOWN)
═══════════════════════════════════════════════════════════════════════════════

Es buena práctica convertir el manual a .md para que se vea mejor en GitHub.

1. Renombra: SADA_MANUAL_USUARIO.txt → MANUAL_USUARIO.md
2. Agrega títulos markdown:
   # Título principal
   ## Subtítulo
   ### Sub-subtítulo
   
   **texto en negrita**
   *texto en itálica*
   `código`

3. Agrega tablas:
   | Columna 1 | Columna 2 |
   |-----------|----------|
   | Dato 1    | Dato 2    |

Ejemplo de conversión parcial ya está en README.md
