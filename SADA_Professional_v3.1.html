📈 Análisis de Desempeño

Cálculo automático, diagnóstico académico y plan semanal

El PDF respeta el alcance de tu rol: Admin ve todo, Docente sus alumnos, Estudiante solo su información y Padre sus hijos. Si hay más de un alumno visible, se preguntará si deseas descargar todos o uno en específico.

¿Qué datos analiza esta pestaña?

El promedio se calcula con las notas visibles del estudiante. La tendencia compara la primera y la última nota registrada. El riesgo considera promedio, cantidad de notas desaprobadas y cursos evaluados. Esta información sirve como referencia académica, no reemplaza el criterio del docente o tutor.

📊 Plan de Mejora Semanal

Seguimiento visual del desempeño y acciones concretas para mejorar

¿Cómo se calcula este plan?

El gráfico de barras usa las notas visibles del estudiante ordenadas por fecha y las agrupa en semanas académicas. Cada barra representa el promedio de esa semana. El plan sugiere acciones según desempeño: reforzar cursos bajos, mantener hábitos si el rendimiento es bueno y alertar si hay riesgo.

Selecciona un estudiante para ver su plan de mejora semanal.

🎯 Orientación Vocacional

Recomendación personalizada por área de afinidad

Cómo funciona la orientación vocacional

SADA estima áreas de afinidad usando las notas del estudiante por curso. Por ejemplo: Matemática, CTA y Computación fortalecen Ingeniería/Tecnología; Comunicación y Ciencias Sociales fortalecen Humanidades; Arte y Comunicación fortalecen Artes. También se muestra una frase motivacional personalizada para reforzar el esfuerzo.

Selecciona un estudiante para ver su perfil vocacional

Privacidad y alcance del prototipo

🔐 Privacidad

El prototipo valida permisos por rol. En producción debe usar backend, hash de contraseñas, cifrado y protección de datos de menores.

🧩 Alcance MVP

Demuestra usuarios, cursos, notas, análisis, orientación vocacional, PDF e integración simulada. No reemplaza una arquitectura cloud real.

🗂️ Trazabilidad Word

Conserva los requerimientos del documento: dashboard, reportes, orientación vocacional, roles, seguridad básica e interoperabilidad LMS.

🚀 Futuro productivo

Frontend + API backend + PostgreSQL + autenticación segura + cloud + conectores LMS + motor ML.
